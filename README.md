# Code Practice Portfolio

Daily coding practice and system design notes for software engineering, SRE, and platform engineering growth.

## Structure

- `coding/`: Java solutions for data structures, algorithms, and system-design-related coding exercises.
- `coding/notes/`: Short explanations with approach and complexity.
- `system-design/`: Practical notes on distributed systems, infrastructure, and platform concepts.

## Focus Areas

- Arrays, strings, trees, graphs, heaps, sliding window, two pointers, and backtracking
- Rate limiters, caches, queues, load balancing, observability, and Kubernetes concepts
- Clean Java implementations with concise technical write-ups
